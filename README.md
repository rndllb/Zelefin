## Servers

<table>
<tr>
<td width="33%" valign="top">

**🪼 Jellyfin** · ready

Sign in with URL, username, and password. Extra accounts live in the profile sheet. Full admin, SyncPlay, plugin alerts, Live TV (iOS).

</td>
<td width="33%" valign="top">

**🗄️ Silo** · ready

Same app. Household profiles and PIN after login. Jellyfin-only dashboard tools stay hidden (users, plugins, backups, branding, tasks).

</td>
<td width="33%" valign="top">

**⏳ Emby & Plex** · next

Not in this build. The UI is already native on both phones; those sign-ins ship later.

</td>
</tr>
</table>

The optional [Zelefin plugin](https://github.com/rndllb/Zelefin-Plugin) is Jellyfin-only. It pushes lock-screen alerts and dashboard messages while the app is closed.

## What you get

<table>
<tr>
<td width="33%" valign="top">

### 🏠 Home

Continue watching, next up, recently added, and latest from each library. Reorder or hide rows. Featured hero from Interface settings.

</td>
<td width="33%" valign="top">

### 📚 Library

Movies, shows, collections, favorites, playlists. Filter by type, genre, year, rating. Sort, randomize, A–Z jump.

</td>
<td width="33%" valign="top">

### 🔎 Search

Search the signed-in server. **Discover** and request missing titles when Seerr is signed in (or Silo’s request plugins).

</td>
</tr>
<tr>
<td width="33%" valign="top">

### 🎞️ Title

Backdrop, overview, seasons, similar, chapters, extras, special features. Play / resume with progress.

</td>
<td width="33%" valign="top">

### 👥 People

Cast and crew photos from the server. Open a person and browse their titles.

</td>
<td width="33%" valign="top">

### ⬇️ Downloads

Movies and episodes for offline play. Downloads tab with storage totals. Progress on posters and detail.

</td>
</tr>
<tr>
<td width="33%" valign="top">

### ▶️ Playback

Play, pause, skip, speed, audio, subtitles, chapters. Resume from the server. Direct play when the device can decode; transcode only when it cannot.

</td>
<td width="33%" valign="top">

### 🎨 Picture & sound

HDR, Dolby Vision, Atmos badges when the file has them. Cinema bumpers. Intro / credits skip. Subtitle size, color, and position.

</td>
<td width="33%" valign="top">

### 👯 SyncPlay

Jellyfin groups. Pause, seek, and play stay together — including with the official web client. The group waits, then everyone starts.

</td>
</tr>
<tr>
<td width="33%" valign="top">

### 📡 Sessions

See other devices, send play / playstate, send a Display Message. In-app popup while Zelefin is open.

</td>
<td width="33%" valign="top">

### 🔔 Notifications

Library adds, streams starting, users online, tasks, Seerr requests. Per-kind toggles. Lock screen needs the Jellyfin plugin.

</td>
<td width="33%" valign="top">

### 🛠️ Admin

Jellyfin administrators: users, libraries, plugins, scheduled tasks, activity, backups, branding, scan, dashboard.

</td>
</tr>
<tr>
<td width="33%" valign="top">

### ⚙️ Settings

Appearance, home rows, playback languages, downloads, notifications, which tabs sit in the dock, and the page the app opens to. Theme and poster text.

</td>
<td width="33%" valign="top">

### 🔌 Plugins

Intro Skipper, Open Subtitles, Jellyfin Enhanced, Seerr / Jellyseerr. First-run setup can install the Zelefin companion.

</td>
<td width="33%" valign="top">

### 🎲 Extra

Randomize in the library. Show tab names on the dock (on by default on Android). Review Demo on iPhone / iPad — no server.

</td>
</tr>
</table>

## Run it

<table>
<tr>
<td width="50%" valign="top">

### 🍎 Xcode

1. Open `IOS/Zelefin.xcodeproj`
2. Pick a simulator or a signed-in device
3. Run

`IOS/project.yml` regenerates the project if you need XcodeGen.

[iOS notes →](IOS/README.md)

</td>
<td width="50%" valign="top">

### 🤖 Android Studio

1. Open the `Android/` folder
2. Pick an emulator or a USB-debugged device
3. Run the `app` configuration

Needs Android 8 (API 26)+.

[Android notes →](Android/README.md)

</td>
</tr>
</table>

**Needs:** iOS 26, or Android 8+, and a Jellyfin or Silo server the device can reach.

```bash
cd IOS
xcodebuild test -scheme Zelefin -destination 'platform=iOS Simulator,name=iPhone 17 Pro'
```
