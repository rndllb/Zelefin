Zelefin

Support

Zelefin is a native Jellyfin and Silo client for iPhone, iPad, and Android. Emby and Plex are coming. Your media stays on the server you connect to. The app is free. There is no Plus plan and nothing to restore.

App

iPhone, iPad, and Android: github.com/rndllb/Zelefin

Plugin

Lock-screen alerts, closed-app messages, and shared plugin settings for Jellyfin: github.com/rndllb/Zelefin-Plugin. Apple devices use APNs. Android uses Firebase Cloud Messaging. Silo does not use the plugin.

Bugs

Open an issue on the app or plugin repository. Include the version and build from Settings → About if you can.
